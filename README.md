# CRM для транспортной компании

Дипломный проект.

**Стек:** React + Vite + SCSS + i18next (frontend), FastAPI + PostgreSQL + Redis (backend), Docker + Nginx.

**Статус:** в разработке.

## Структура

- `frontend/` — клиентская часть
- `backend/` — серверная часть
- `docs/` — проектная документация
