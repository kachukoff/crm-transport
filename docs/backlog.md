# Бэклог (после защиты)

Идеи, которые не входят в текущий scope. Не реализовывать до защиты.

- Email-рассылки клиентам о статусе заказа (`fastapi-mail`).
- Репликация Postgres (master/slave).
- Интеграция с картами (Яндекс.Карты) — точные координаты, карта в карточке заказа.
- Экспорт заказов в Excel/PDF.
- CI на GitHub Actions.
- Мобильное приложение для водителей.
- Аналитика и отчёты (выручка по месяцам, топ клиентов).
- Договорные цены для постоянных клиентов.
- Учёт топлива и расходов на рейс.
- CSRF-защита для форм (публичная заявка + авторизованные запросы).
- Переработка формы заявки: минимум обязательных полей, остальное — опционально.
